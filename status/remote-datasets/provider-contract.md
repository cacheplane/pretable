# Task 2: provider and query contract decisions

This slice exports provider wire types, query preparation and identities only. It does not construct a remote model, invoke providers, validate provider responses, schedule work, integrate React, or implement export jobs. Later controller code must call preparation before `open` and validate all counts/ranges/identities before publication. The minimal read handle describes observation without promising unimplemented controller commands. React overload/type exclusion tests belong to Task 10 when that surface exists.

Query configuration reuses the existing typed filters and grouping columns. Leaf sorts require explicit comparison registry keys and null order. Optional legacy grouping direction/nulls fields are rejected: remote ordering is exclusively in `groupSort`. Every grouping level requires explicit sibling sorts; stable typed identity is the final tie breaker at both levels. Comparison, aggregate and overall registry versions are semantic inputs. Registered aggregate IDs identify effective column-specific definitions (including options/version), and must be unique within a query. A server registry can give multiple sum definitions distinct IDs for different fields. No closures cross this boundary. Column editor settings are outside query configuration.

The canonical query key is a full stable typed encoding, not a cryptographic digest and not a diagnostic string. It may contain sensitive filter/search values: never log or persist it as diagnostic text. Authorization scope is an opaque identity without credentials. Unknown fields are rejected rather than silently excluded from identity. Arrays preserve ordering; object insertion order does not matter. Semantically equivalent but differently ordered filters may conservatively produce different keys. JSON-safe remote keys explicitly exclude undefined/bigint; adapters must define a canonical registry encoding when those local values occur.

Preparation checks declared operators, operands, fields, aggregate/comparison IDs, grouping depth, search support, and exact ordinal access. Backend authorization, trusted schema mapping, resource limits and unsupported cross-field/operator combinations remain provider responsibilities: `open` must return a typed diagnostic before executing an unsupported query. These declarations do not claim client checks are a security boundary.

The provider opens a session with exact immediate root count; each group carries exact child count. Range requests and answers use `[start,end)` sibling ordinals and echo session/query/token/route. Counts must be nonnegative safe integers; later response validation must prove entries fill the requested range except at the exact end and reconcile overlaps. `sessionId` identifies provider resources separately from a result token. The controller will additionally own an acceptance generation; selection must bind query key, result token and generation even when refresh returns an unchanged token. Cancellation uses an AbortSignal-compatible structural subset that compiles with ES2022 and no DOM library. Release is per provider session.

Aggregate answers explicitly distinguish ready (complete/partial), unavailable, and error. A ready zero is data; absence is not zero. Each answer carries the existing `aggregateDefinitionKey` concept and server authority. Group answers inherit query/token/session provenance from their range and filtered descendant scope from their route; summary answers explicitly carry session/query/token, filtered/all scope and registry/aggregate IDs. Providers must aggregate the whole authorized scope, never average cached page aggregates. Compatibility validation and adaptation to the existing summary surface are deferred to controller/presentation tasks.

The separate remote slot union carries loading/error positions without business records or selectable IDs. Existing local unions and React input behavior are untouched. Full-result same-version server export remains required for the release and is intentionally deferred to its planned implementation task, not represented by a placeholder callback here.
