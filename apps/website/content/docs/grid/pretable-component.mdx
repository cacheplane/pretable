`<Pretable>` is the shortest path to a grid. Pass typed rows and columns; it uses the same indexed local row model as `<PretableSurface>`.

```tsx
import { createColumnHelper } from "@pretable/core";
import { Pretable } from "@pretable/react";

interface Person {
  id: string;
  name: string;
  city: string;
}

const column = createColumnHelper<Person>();
const columns = [
  column.accessor("name", { type: "text", header: "Name" }),
  column.accessor("city", { type: "text", header: "City" }),
] as const;

export function People({ rows }: { rows: readonly Person[] }) {
  return <Pretable rows={rows} columns={columns} />;
}
```

Use [`<PretableSurface>`](/docs/grid/pretable-surface) when you need controlled state, grouping controls, custom renderers, editing callbacks, clipboard overrides, explicit row-model ownership, or telemetry.
