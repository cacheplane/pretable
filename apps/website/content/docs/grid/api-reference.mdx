Type signatures for the public API of `@pretable/react`. Hand-authored from the source at `packages/core/src/types.ts` and `packages/react/src/use-pretable.ts`. Pre-1.0 — names may rename or remove in patch releases.

## `PretableColumn<TRow>`

A column definition. Generic over your row type.

| Field          | Type                                                    | Required | Description                                                                                                                                                                                                                                                                                                                                      |
| -------------- | ------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`           | `string`                                                | yes      | Unique column identifier. Used as React key, sort target, filter target, focus target.                                                                                                                                                                                                                                                           |
| `header`       | `string`                                                | no       | Column header label. Defaults to the column `id` if omitted.                                                                                                                                                                                                                                                                                     |
| `wrap`         | `boolean`                                               | no       | If `true`, cells in this column wrap content vertically (sets `[data-pretable-wrap="true"]`).                                                                                                                                                                                                                                                    |
| `widthPx`      | `number`                                                | no       | Fixed pixel width. Defaults to 220 for wrapping columns, 140 for non-wrapping.                                                                                                                                                                                                                                                                   |
| `pinned`       | `"left" \| "right"`                                     | no       | Pin the column to a viewport edge. Sets `[data-pretable-pinned]` to the same value on the cell. Pinned columns are never virtualized away. See [Column layout](/docs/grid/column-layout#pin).                                                                                                                                                    |
| `sortable`     | `boolean`                                               | no       | Whether the column can be sorted. Defaults to `true` if a `value` is provided.                                                                                                                                                                                                                                                                   |
| `filterable`   | `boolean`                                               | no       | Whether the column can be filtered. Defaults to `true` if a `value` is provided.                                                                                                                                                                                                                                                                 |
| `type`         | `ColumnType`                                            | no       | Declares what the column holds. Drives three things at once: the [filter operators](/docs/grid/filtering#operators) offered, the [typed editor](/docs/grid/editing#typed-editors) rendered, and the [clipboard type hint](/docs/grid/clipboard#type-hints). Untyped columns fall back to text behavior everywhere but receive no clipboard hint. |
| `options`      | `ColumnOption[]`                                        | no       | The allowed values for an `enum` column. Drives the combobox editor and the `isAnyOf` / `isNoneOf` filter operators. Ignored for other types.                                                                                                                                                                                                    |
| `value`        | `(row: TRow) => unknown`                                | no       | Extract the cell value from the row. If omitted, the column has no sortable/filterable value.                                                                                                                                                                                                                                                    |
| `format`       | `(input: PretableFormatInput<TRow>) => string`          | no       | Per-cell string formatter. Drives display and copy. See [Cell renderers](/docs/grid/cell-renderers).                                                                                                                                                                                                                                             |
| `render`       | `(input: PretableCellRenderInput<TRow>) => ReactNode`   | no       | Per-cell ReactNode renderer. Receives `formattedValue` from `format`. See [Cell renderers](/docs/grid/cell-renderers).                                                                                                                                                                                                                           |
| `renderHeader` | `(input: PretableHeaderRenderInput<TRow>) => ReactNode` | no       | Per-column header renderer. See [Cell renderers](/docs/grid/cell-renderers).                                                                                                                                                                                                                                                                     |
| `renderEditor` | `(input: PretableEditorInput<TRow>) => ReactNode`       | no       | Replace the built-in editor for this column. See [Custom editors](/docs/grid/editing#custom-editors).                                                                                                                                                                                                                                            |
| `minWidthPx`   | `number`                                                | no       | Per-column minimum width clamp. Applied during resize and autosize. Engine default min is 40.                                                                                                                                                                                                                                                    |
| `maxWidthPx`   | `number`                                                | no       | Per-column maximum width clamp. Applied during resize and autosize. Engine default max is 800.                                                                                                                                                                                                                                                   |
| `resizable`    | `boolean`                                               | no       | If `false`, the column has no resize handle and `setColumnWidth` is a no-op for it. Defaults true.                                                                                                                                                                                                                                               |
| `reorderable`  | `boolean`                                               | no       | If `false`, header drag does not trigger reorder for this column. Defaults true.                                                                                                                                                                                                                                                                 |
| `align`        | `ColumnAlign`                                           | no       | Horizontal alignment of cells and header label. Defaults to `"end"` for `type: "number"`, and to the writing direction otherwise.                                                                                                                                                                                                                |
| `flex`         | `number`                                                | no       | Share of the width the fixed columns leave over, so the row ends exactly at the viewport edge. Weights are relative. `minWidthPx`/`maxWidthPx` still apply, and a resized column (which sets `widthPx`) stops flexing. See [Column layout](/docs/grid/column-layout).                                                                            |

### Row grouping fields

See [Row grouping](/docs/grid/grouping).

| Field             | Type                                                    | Description                                                                                                                                                                                      |
| ----------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `rowGroup`        | `boolean`                                               | Group rows by this column; levels follow column order. A **seed only** — read once when the grid is created. Changing it later does nothing; use `state.rowGroups` or `grid.setRowGroups`.       |
| `aggregate`       | `PretableAggregateSpec`                                 | The aggregate shown for this column on group rows: `"sum" \| "avg" \| "min" \| "max" \| "count"`, or a custom `PretableAggregator`.                                                              |
| `formatAggregate` | `(input: PretableAggregateFormatInput<TRow>) => string` | Formats this column's aggregate on a group row. **Not `format`** — `PretableFormatInput.row` is non-optional and a group row has no row, so a cell formatter is not a legal aggregate formatter. |

### Cell editing fields

All optional, and all inert unless the grid has an `onCellEdit` handler. See [Editing](/docs/grid/editing).

| Field             | Type                                                                         | Description                                                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `editable`        | `boolean \| (input: PretableEditInput<TRow>) => boolean \| Promise<boolean>` | Whether cells in this column can be edited. A function form decides per cell and may be async. Off by default. See [Making a column editable](/docs/grid/editing#making-a-column-editable). |
| `validate`        | `(value, input) => (true \| string) \| Promise<true \| string>`              | Reject a pending edit. Return `true` to accept, or a string to surface as the error message. May be async. See [Validating](/docs/grid/editing#validating).                                 |
| `parseEditValue`  | `(raw: string, input: PretableEditInput<TRow>) => unknown`                   | Turn the editor's raw string into the value written back to your row. Overrides the built-in parse for the column's `type`.                                                                 |
| `formatEditValue` | `(value: unknown, input: PretableEditInput<TRow>) => string`                 | Turn the cell value into the editor's initial string. The inverse of `parseEditValue`. Distinct from `format`, which drives display and copy, not the editor.                               |
| `step`            | `number`                                                                     | Increment for a `number` editor's ArrowUp/ArrowDown and steppers. Defaults to 1.                                                                                                            |

### `ColumnType` and `ColumnOption`

```ts
type ColumnType = "text" | "number" | "date" | "enum" | "boolean";

interface ColumnOption {
  value: string;
  label?: string; // falls back to `value`
}
```

One `type` declaration drives filtering, editing, and clipboard behavior together — you do not configure them separately. `options` is only meaningful when `type` is `"enum"`.

## `PretableRow`

```ts
type PretableRow = Record<string, unknown>;
```

Your row type extends this. The engine treats rows as opaque records; only `getRowId` and `value` access fields.

## Cell renderer types

Inputs passed to per-column `format`, `render`, and `renderHeader`.

```ts
interface PretableFormatInput<TRow extends PretableRow = PretableRow> {
  value: unknown;
  row: TRow;
  column: PretableColumn<TRow>;
}

interface PretableCellRenderInput<
  TRow extends PretableRow = PretableRow,
> extends PretableFormatInput<TRow> {
  formattedValue: string;
  rowId: string;
  rowIndex: number;
  isFocused: boolean;
  isSelected: boolean;
  pinned: "left" | "right" | null;
}

interface PretableHeaderRenderInput<TRow extends PretableRow = PretableRow> {
  column: PretableColumn<TRow>;
  label: string;
  sortDirection: "asc" | "desc" | null;
  isSorted: boolean;
  pinned: "left" | "right" | null;
}

// The aggregate counterpart of PretableFormatInput. Note there is no `row`:
// an aggregate belongs to a group, not to a data row.
interface PretableAggregateFormatInput<TRow extends PretableRow = PretableRow> {
  value: unknown;
  column: PretableColumn<TRow>;
  group: PretableGroupRow;
}
```

`pinned` is the authoritative pin side, read from the engine's column plan
rather than the `columns` prop — pins applied through controlled
`state.columnPinned`, `grid.setColumnPinned`, or drag-to-pin never write back to
the prop. It is normalized to `null` when the column is unpinned, unlike
`column.pinned`, which is `undefined` in that case.

`PretableCoreColumn<TRow>` is the engine-level (React-free) column type re-exported from `@pretable/core`. `PretableColumn<TRow>` extends it with the React-only `render` and `renderHeader` fields. Most consumers import `PretableColumn` from `@pretable/react`.

`PretableAggregateFormatInput` is exported from `@pretable/core` only — writing a `formatAggregate` inline on a `PretableColumn` infers it, so you rarely need the name.

- `PretableCellAddress` — a single cell, identified by stable row + column id.
- `PretableCellRange` — a rectangular range over ids; survives sort/filter/reorder.
- `PretableSelectionState` — the engine's full selection slice (ranges plus the anchor for shift-extends).
- `PretableFocusState` — the focused cell address; nullable on each axis when focus has not landed yet.
- `PretableFocusDirection` — direction argument for `grid.moveFocus`.
- `PretableMoveFocusOptions` — modifier flags that turn `moveFocus` into shift-extend, edge-jump, or page-step.
- `PretableRowSelectionTriState` — derived per-row state for the checkbox column header (full = `"selected"`, mixed = `"indeterminate"`; absent means unchecked). Exported from `@pretable/core`.

## Surface configuration types

```ts
interface PretableSortEntry {
  columnId: string;
  direction: "asc" | "desc";
}

interface PretableSurfaceState {
  sort?: PretableSortEntry[];
  filters?: Record<string, ColumnFilter>;
  selection?: PretableSelectionState;
  focus?: PretableFocusState;
  columnWidths?: Record<string, number>;
  columnOrder?: readonly string[];
  columnPinned?: Record<string, "left" | "right" | null>;
  rowGroups?: string[]; // grouping columns, outermost first; [] ungroups
}

interface RowSelectionColumnConfig {
  enabled: true;
  position?: "left"; // v1: left only
  pinned?: boolean; // default true
  headerCheckbox?: boolean; // default true
  width?: number; // default 36
}

interface PretableSurfaceMessages {
  selectAllAnnouncement?: (args: {
    rowCount: number;
    columnCount: number;
    isAll: boolean;
  }) => string;
  copyAnnouncement?: (args: {
    rowCount: number;
    columnCount: number;
  }) => string;
  copyFailedAnnouncement?: () => string;
  pasteAnnouncement?: (args: {
    cellCount: number; // cells actually written
    rejectedCount: number; // cells refused by editable/validate
    clipped: { rows: number; columns: number }; // PastePayload.clipped
  }) => string;
  pasteFailedAnnouncement?: () => string;
  groupExpandedAnnouncement?: (args: {
    label: string;
    childCount: number;
  }) => string;
  groupCollapsedAnnouncement?: (args: {
    label: string;
    childCount: number;
  }) => string;
}
```

- `PretableSortEntry` — one entry in the ordered sort list; index in the list = priority, `[]` = unsorted. See [Sorting](/docs/grid/sorting).
- `PretableSurfaceState` — the slice-based controlled-state shape passed via the surface's `state` prop. Each slice is independently controlled.
- `RowSelectionColumnConfig` — opts for the built-in checkbox column. Pass to `<PretableSurface>`'s `rowSelectionColumn` prop.
- `PretableSurfaceMessages` — overrides for the polite `aria-live` announcements (select-all, copy/paste success/failure, and group expand/collapse). `pasteAnnouncement` is one function rather than one per outcome because a clean, partial and wholly rejected paste are the same sentence at different counts, and clipping is orthogonal to all three. See [Paste](/docs/grid/paste#announcements) and [Row grouping](/docs/grid/grouping#keyboard).

## `PretableGridSnapshot<TRow>`

```ts
interface PretableGridSnapshot<TRow extends PretableRow = PretableRow> {
  viewport: {
    scrollTop: number;
    scrollLeft: number;
    height: number;
    width: number;
  };
  sort: { columnId: string; direction: "asc" | "desc" }[]; // PretableSortEntry[] — index = priority
  filters: Record<string, ColumnFilter>;
  selection: {
    ranges: Array<{
      startRowId: string;
      endRowId: string;
      startColumnId: string;
      endColumnId: string;
    }>;
    anchor: { rowId: string; columnId: string } | null;
  };
  focus: { rowId: string | null; columnId: string | null };
  totalRowCount: number;
  visibleRows: PretableVisibleRow<TRow>[];
  visibleRange: { start: number; end: number };
  editing: PretableEditState | null;
  // Row grouping:
  rowGroups: string[]; // grouping columns, outermost first; [] when ungrouped
  groupsDefaultExpanded: boolean;
  groupExpansionOverrides: ReadonlySet<string>; // ids that DIFFER from the default
}
```

Read via `grid.getSnapshot()` or directly from the `usePretable` return value.

`visibleRows` is a union, not a row array — a grouped grid interleaves group headers among the data rows:

```ts
type PretableVisibleRow<TRow> = PretableDataRow<TRow> | PretableGroupRow;

interface PretableDataRow<TRow> {
  kind: "data";
  id: string;
  row: TRow;
  sourceIndex: number;
  depth: number; // 0 when ungrouped
}

interface PretableGroupRow {
  kind: "group";
  id: string; // stable and path-derived
  depth: number; // 0 is the outermost level
  columnId: string; // the column this level groups by
  value: unknown; // the group key
  childCount: number; // data rows beneath it, post-filter
  aggregates: Record<string, unknown>; // finalized values, keyed by column id
}
```

## `PretableRenderSnapshot<TRow>`

Tells you which rows to render and where to position them.

```ts
interface PretableRenderSnapshot<TRow> {
  columns: PlannedColumn[];
  rows: PretableRenderRow<TRow>[];
  nodeCount: number;
  totalHeight: number;
  totalWidth: number;
  // Widths of the two sticky pinned column groups.
  pinnedLeftWidth: number;
  pinnedRightWidth: number;
  // Geometry for EVERY visible row, not just the rendered window.
  rowMetrics: {
    readonly rowCount: number;
    getHeight(index: number): number;
    getOffsetForIndex(index: number): number;
    getTotalHeight(): number;
  };
}

// A union, discriminated on `kind` — a grouped grid renders group headers
// interleaved with the data rows.
type PretableRenderRow<TRow> =
  PretableRenderDataRow<TRow> | PretableRenderGroupRow;

interface PretableRenderRowGeometry {
  id: string;
  rowIndex: number; // index into snapshot.visibleRows
  top: number;
  height: number;
}

interface PretableRenderDataRow<TRow> extends PretableRenderRowGeometry {
  kind: "data";
  row: TRow;
}

interface PretableRenderGroupRow extends PretableRenderRowGeometry {
  kind: "group";
  group: PretableGroupRow;
}

interface PlannedColumn {
  id: string;
  index: number;
  left: number;
  width: number;
  pinned?: "left" | "right";
  // Right-pinned columns only: offset from the viewport's RIGHT edge.
  right?: number;
}
```

`renderSnapshot.rows` is the slice of rows currently visible in the viewport (plus overscan). Each has `top` (the absolute Y position) and `height` (the row's height — measured if you provided `measuredHeights`, otherwise estimated). Use these to position your row JSX with `position: absolute; top: ${row.top}px; height: ${row.height}px`.

`renderSnapshot.columns` is the column layout, planned from the **drawn** column list (`grid.getColumns()`), so while grouping is active it includes the derived group column and excludes the grouped ones — left offset and width per column, accounting for pinned positioning. Left-pinned columns come first, then the visible scrollable window, then the right-pinned columns. A right-pinned entry additionally carries `right`, its offset from the viewport's right edge, which is what its sticky position is derived from; its `left` is still the column's true content offset (where it sits in the end-to-end layout), so mapping any entry back to a content coordinate works uniformly.

`renderSnapshot.rowMetrics` covers **every** visible row, including rows outside the rendered window that `renderSnapshot.rows` omits — that is what makes it possible to compute a scroll offset for a row that has no DOM node yet. Together with `pinnedLeftWidth` / `pinnedRightWidth` it's the state `<PretableSurface>` uses for [scroll-into-view on keyboard focus](/docs/grid/keyboard#scroll-follows-focus); a custom renderer needs the same inputs to reproduce it. The `rowMetrics` interface is fully typed but isn't exported under a name — write it down as `PretableRenderSnapshot["rowMetrics"]` if you need to.

## `PretableTelemetry`

```ts
interface PretableTelemetry {
  focusedRowId: string | null;
  rowModelRowCount: number;
  renderedRowCount: number;
  selectedRowId: string | null;
  totalRowCount: number;
  totalHeight: number;
  visibleRowCount: number;
  visibleRowRange: { start: number; end: number };
}
```

Useful for instrumentation (frame budget tracking, visible-row counts, focus survival across filters).
