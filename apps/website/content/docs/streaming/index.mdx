`@pretable/stream-adapter` connects an async source to an explicit row model. It coalesces producer events into at most one atomic row-model transaction per animation frame.

For ordinary React data, use the declarative `rows` prop. Choose explicit row-model ownership when a high-frequency producer needs to publish transactions directly.

```ts
import { createLocalRowModel } from "@pretable/core";

const rowModel = createLocalRowModel({ rows: [], columns });
```

## Pick the source shape

<Tabs>
  <Tab label="Element streams">
    Each element is a complete new row.

    ```ts
    import { connectElementStream } from "@pretable/stream-adapter";

    const connection = connectElementStream(rowModel, rows);
    await connection.done;
    ```

  </Tab>
  <Tab label="Partial streams">
    Each partial updates one fixed row ID. Seed it first or provide `createRow`.

    ```ts
    import { connectPartialStream } from "@pretable/stream-adapter";

    const connection = connectPartialStream(rowModel, partials, {
      rowId: "assistant-1",
      createRow: (partial, id) => ({
        id,
        role: "assistant",
        content: partial.content ?? "",
      }),
    });
    ```

  </Tab>
</Tabs>

`dispose()` stops consumption; `done` resolves on completion/disposal and rejects with source or model failures.
